# Battle ability audit

Scope: all 314 PokéAPI abilities with IDs 1–314. IDs above 10000 are excluded. No eligible ID is skipped.

**Result: every singles-applicable ability has an engine hook.** The audit found 295 abilities with a local branch or supplemental rule, 19 whose documented effect cannot affect this singles format, and 0 with no ability-specific local handler.

A “local branch” means only that relevant code or structured supplemental data exists; it does not claim complete parity. Each ability also passes a bounded construction and numeric-invariant check. The JSON report preserves the full PokéAPI effect and all requested behavior dimensions.

Sources: PokéAPI ability payloads and the current Pokémon Showdown ability table. Reference SHA-256: `e942ef6a75cdd50095f6b68c27e772ea91f2202714a30b04539ff17b7b93c065`.

Battle rules follow the current Pokémon Showdown reference, including where historical PokéAPI descriptions differ. The engine models move flags, weight, forms, temporary abilities, suppression and per-battle activation state. Exclusively doubles or wild-encounter abilities remain explicitly inapplicable; no substitute singles effects are invented. The behavioral suite in battle-abilities.test.ts exercises the hooks and battle timing; the catalog classification alone does not certify full cartridge parity.
